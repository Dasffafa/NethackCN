# Nethack 3.7 汉化工程

## 参与汉化工程

1. 在电脑上安装VSCode.
2. 安装 Compare Folders@MoshFeu插件。
3. 在“资源管理器"选项卡中同时选择upstream文件夹和NethackCN中的对应文件夹（按住Shift），然后右键点击Compare Folders,将原版文件和翻译文件进行对比。
4. 直接编辑NethackCN文件夹中的源代码。
5. 将改动提交到本项目。

## 项目规范

1. 本项目提交代码需项目拥有者审核，非睡觉时间（早8：00到晚11：30）保证3小时之内审核，其余时间一般无法审核。
2. 对于可能存在双关的翻译，如果你不理解，最好暂时保留，发到群里询问众人意见，以便得到更好的翻译结果。如果你理解并成功翻译了，请在翻译文本旁加上对应的注释。
3. 对于幻觉状态下的文本，原则上不做过多要求。能看出来和正常状态下的文本有关系就行。
4. 可以对代码进行适当的修改。例如Your、You_feel等函数，在影响语言通顺的前提下，可以替换为其他的函数。某些情况下，%s的参数的语序也应当交换。
5. 因为yuer汉化版本带来的广泛影响力，对于yuer翻译版的文本，如果没有翻译错误，应尽量采用该版本翻译，以最小化多个版本间的不统一。yuer的3.6.7汉化版代码可以在[这里](https://github.com/SunnyYuer/NetHack-cn/archive/refs/heads/NetHack-Android.zip)下载，下载后同样可以使用文件比较工具参考汉化。
6. 对于原文的英文标点符号，统一汉化为英文半角标点符号+空格的形式。
